## Architectural Decisions
- Account deletion: soft delete + PII anonymization (name→"Deleted User", email→hash, image→null)
- Deletion confirmation: type "DELETE" dialog (no email confirmation — soft delete is reversible)
- Cookie consent: localStorage-based, gates Vercel Analytics, no backend needed
- Data export: read-only aggregation from existing repos, JSON download

## Design Specifications (PR1)

### Privacy Page Layout
Follow the **security page pattern** (`security/page.tsx`):
- `PublicHero` with eyebrow "Legal", heading with Fraunces italic emphasis, description
- **Table of Contents** — anchor links to each section, `max-w-3xl`, `border-l-2 border-primary/30`
- **Major sections** use icon+heading+body pattern (lucide icon + h2 Fraunces + Geist body)
- Alternating section backgrounds: white → `bg-[#F5F4F0]` → white → etc.
- Prose width: `max-w-3xl` (~65ch per DESIGN.md)
- Section headings: `text-[32px] font-display font-bold`
- Body text: `text-sm leading-relaxed text-muted-foreground`

Section icons (lucide-react):

### Cookie Consent Banner Design

**Component:** `CookieConsentBanner` (client component in root layout)
**Position:** Fixed bottom, `z-50`, `border-t border-border`
**Background:** `bg-background` (`#FAFAF8`)
**Flash prevention:** `useEffect` + localStorage check, render nothing during SSR

**Desktop layout (≥768px):**
```
┌──────────────────────────────────────────────────────────────────┐
│  We use cookies to improve your experience and analyze usage.    │
│                                                                  │
│  [Manage preferences]    [Decline All]    [Accept All]           │
└──────────────────────────────────────────────────────────────────┘
```

**Mobile layout (<768px):**
```
┌────────────────────────────┐
│  We use cookies...         │
│                            │
│  [Accept All          ]    │
│  [Decline All         ]    │
│  Manage preferences ▸      │
└────────────────────────────┘
```

**Expanded preferences panel (slide-down):**
```
┌──────────────────────────────────────────────────────────────────┐
│  Cookie Preferences                                              │
│                                                                  │
│  Essential         Session auth, security features    [====] on  │
│  Analytics         Anonymous usage statistics          [    ] off │
│                                                                  │
│  [Save Preferences]                             [Accept All]     │
└──────────────────────────────────────────────────────────────────┘
```

**Button tokens:**
- Accept All: `bg-primary text-primary-foreground` (forest green)
- Decline All: `variant="outline"`
- Manage Preferences: `variant="ghost"` or text link
- Save Preferences: `bg-primary text-primary-foreground`
- Toggle switches: shadcn `Switch` component
- Essential toggle: always on, disabled state

**Accessibility:**
- `role="dialog"`, `aria-label="Cookie preferences"`
- `aria-label` on each toggle switch
- Focus trap when preferences panel is expanded
- All buttons ≥ 44px touch targets
- Privacy/Terms pages: semantic `<article>` + `<nav>` for TOC
- Heading hierarchy: h1 in hero, h2 for sections, h3 for subsections
- Section `id` anchors for direct linking from TOC

**Animation:** Preferences panel slides down with `transition-all duration-300`.
Banner dismissal slides down with same timing.
